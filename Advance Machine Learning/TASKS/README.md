# Image Classification using CNN and Transfer Learning

This project implements multiple deep learning models:

- CNN (from scratch)
- ResNet50 (Transfer Learning)
- DenseNet121 (Transfer Learning)
- EfficientNet-B0 (Transfer Learning)

## Features
- Training & evaluation pipeline
- Accuracy & loss curves
- Confusion matrix
- Misclassified samples visualization

## Dataset
~60,000 images split into train/val/test

## Results
EfficientNet-B0 achieved best performance with high accuracy and efficiency.

## Tech Stack
- PyTorch
- GPU (Kaggle T4)
